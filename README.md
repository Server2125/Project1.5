# Карта производственной кооперации

Веб-платформа для анализа импортозависимости и приоритетов локализации по кодам ТН ВЭД.

## Что это

Сайт показывает производственные цепочки «сырьё → компоненты → конечный товар» по кодам ТН ВЭД.  
Для каждого товара считает импорт, экспорт, производство, рынок, импортозависимость и индекс локализации.  
Формирует рейтинг приоритетных товаров, топ госзакупок и список товаров с тарифной инверсией.

## Структура проекта

- `index.html` — фронтенд (одностраничное приложение).
- `data/` — исходные CSV-выгрузки.
- `api-contract.md` — описание API, которое нужно фронтенду.
- `README.md` — этот файл.
- `.gitlab-ci.yml`, `Dockerfile` — CI/CD и деплой (зона DevOps).

## Как запустить локально

1. Открыть `index.html` в браузере.
2. Загрузить Excel-файл `connection.xlsx` через кнопку «Выбрать Excel».
3. Данные отобразятся на странице.
