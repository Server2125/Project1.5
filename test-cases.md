# Тест-кейсы «Карта кооперации»

## 1. Загрузка Excel
- [ ] Скачать `connection_4.xlsx` → залить через кнопку → таблица появилась
- [ ] Пустой Excel → показано сообщение об ошибке
- [ ] Excel без листа `import` → сайт не падает

## 2. Поиск
- [ ] Ввести код `4203` → показаны совпадения
- [ ] Ввести «пальто» → показаны совпадения
- [ ] Ввести «абырвалг» → «Совпадений нет»
- [ ] Ввести 1 символ → появляется подсказка

## 3. Дерево
- [ ] Выбрать Parent → дерево построилось
- [ ] Нажать «+» / «−» → уровень сворачивается
- [ ] Клик на узел → открывается метрика узла

## 4. Метрики
- [ ] Импорт = сумма `cost_usd`
- [ ] Рынок = производство + импорт − экспорт
- [ ] Импортозависимость = импорт / рынок
- [ ] Локализация = производство / рынок
- [ ] Приоритетный балл посчитан

## 5. Топ приоритетных
- [ ] Список отображается
- [ ] Клик → открывается профиль
- [ ] «Показать ещё 10» работает

## 6. Топ госзакупок
- [ ] Список виден
- [ ] Фильтры «Все / Пром / Вне реестра» работают
- [ ] Переключение сум/GBP работает

## 7. Тарифная инверсия
- [ ] Список отображается
- [ ] «Превышение ↓» сортирует
- [ ] Поиск по коду работает

## 8. Тема и валюта
- [ ] Тёмная / светлая тема переключается
- [ ] Сум / USD переключается
- [ ] Курс применяется ко всем суммам

## 9. API (когда будет)
- [ ] `USE_API = true` → данные из API
- [ ] API отдаёт ошибку → показано сообщение
- [ ] API пустой → сайт не падает
